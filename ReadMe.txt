# Week 3: Unsupervised Learning and Model Evaluation

## Internship
YUVA AI Pioneers Internship – Machine Learning Internship

## Objective
The objective of this project is to apply K-Means and Hierarchical Clustering,
use PCA for dimensionality reduction, and evaluate the clustering results.

## Dataset
The Iris dataset from scikit-learn was used. It contains 150 samples and
four numerical features.

## Algorithms
- K-Means clustering
- Hierarchical Agglomerative Clustering
- Principal Component Analysis

## Evaluation Metrics
- Silhouette Score
- Davies-Bouldin Index
- Calinski-Harabasz Score

## How to Run
1. Install the required libraries.
2. Open `week3_clustering.ipynb`.
3. Run all cells from top to bottom.

## Results
The notebook contains the visualizations, evaluation metrics, dendrogram,
and comparison of both clustering algorithms.
